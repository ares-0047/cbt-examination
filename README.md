# Velocity Mock Test Portal

A web-based Computer-Based Test (CBT) platform designed for conducting competitive mock examinations such as GATE, CAT, and IELTS. 

The platform provides a distraction-free, strict black-and-white minimalist interface that closely simulates real-world examination environments. It allows students to register, read standard instructions, and take timed mock tests, while providing administrators with a secure dashboard to track candidate submissions and scores.

## 🚀 Platform Overview

**Candidate Experience:**
* **Streamlined Registration:** Captures essential student details (Name, Q-ID, Phone) before granting access to the examination.
* **Timed Testing Environment:** Enforces a strict 90-minute countdown timer with automatic test submission when the time expires.
* **Dynamic Question Palette:** Features a real-time visual grid indicating question statuses (Answered, Not Answered, Not Visited, and Marked for Review).
* **Specialized Layouts:** Utilizes a standard MCQ layout for technical exams (GATE, CAT) and a custom split-screen reading passage layout for language tests (IELTS).
* **Instant Scorecards:** Calculates scores server-side and immediately provides candidates with a detailed breakdown of their performance upon submission.

**Administrator Experience:**
* **Secure Dashboard:** A protected portal exclusively for organizers and faculty.
* **Result Tracking:** Organizers can view, filter, and track all student submissions, dates, and final percentages in one centralized table.
